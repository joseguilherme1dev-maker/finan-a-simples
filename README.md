# FinançaSimples (Hackathon)

Aplicação web para **controle financeiro pessoal** com dashboard de movimentações e **calendário de lembretes de contas** (editável).

## Problema escolhido

Muita gente perde o controle por causa de **gastos recorrentes e “invisíveis”** (contas mensais, assinaturas, boletos) e por falta de uma visão clara do dinheiro entrando/saindo.

## Solução proposta

- **Dashboard** para registrar ganhos, gastos e metas, com visão geral e histórico.
- **Lembrete de contas** em calendário mensal (editável), com contas recorrentes.
- Integração: ao **registrar o pagamento** de uma conta, ela vira automaticamente um **gasto** no dashboard.


## Tecnologias usadas

- **React 19** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Recharts** (gráficos)
- **Lucide React** (ícones)
- **motion/react** (animações)

## Como executar o projeto

**Pré-requisitos:** Node.js + npm

1. Instale as dependências:

```bash
npm install
```

2. Rode em modo desenvolvimento:

```bash
npm run dev
```

Abra `http://localhost:3000`.

### Build/Preview (opcional)

```bash
npm run build
npm run preview
```
